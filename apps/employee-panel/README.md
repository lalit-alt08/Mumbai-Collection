# Employee panel

React/Vite application for staff orders, inventory, banners and catalog tasks. Run `pnpm install --frozen-lockfile` and `pnpm dev` in this directory. Use `pnpm test` and `pnpm build` for checks.

The development port is configured as 5175. `VITE_API_URL` overrides the API endpoint. See the [project guide](../../README.md) and [feature map](../../docs/feature-map.md).
