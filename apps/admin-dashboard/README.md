# Admin dashboard

React/Vite application for administrator operations and reporting. Run `pnpm install --frozen-lockfile` and `pnpm dev` in this directory. Use `pnpm test` and `pnpm build` for checks.

The development port is configured as 5174. `VITE_API_URL` overrides the API endpoint and `VITE_CUSTOMER_URL` controls the storefront link. See the [project guide](../../README.md) and [feature map](../../docs/feature-map.md).
